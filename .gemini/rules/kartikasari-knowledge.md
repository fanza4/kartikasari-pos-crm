Selalu gunakan struktur harga dan isi paket berikut:

### Varian Utama Mie Baso
- **Pilihan Mie**: Mie Kuah, Mie Yamin Manis, Mie Yamin Asin

### Paket Porsi & Komposisi
- **Seporsi (Rp 26.000)**: Mie + 1 Baso Urat + 3 Baso Kecil (Kuah / Yamin Manis / Yamin Asin)
- **Setengah Porsi (Rp 20.000)**: Mie + 3 Baso Kecil (Kuah / Yamin Manis / Yamin Asin)
- **Komplit (Rp 48.000)**: Mie + 1 Baso Urat + 3 Baso Kecil + Tahu + Siomay (Khusus Mie Kuah & Yamin Manis)
- **Komplit Khusus Yamin Asin (Rp 40.000)**: Mie + 1 Baso Urat + 3 Baso Kecil + Tahu + Siomay (*Harga khusus Rp 40.000*)
- **1/2 + Tambah Baso (Rp 35.000)**: Mie + 1 Baso Urat + 5 Baso Kecil
- **1/2 + Tambah Siomay (Rp 29.000)**: Mie + 3 Baso Kecil + 1 Siomay
- **1/2 + Tambah Tahu (Rp 29.000)**: Mie + 3 Baso Kecil + 1 Tahu
